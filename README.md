# Future Header Git Exercise

This repository demonstrates:
1. Creating the `future_header` branch.
2. Adding and committing a header on that branch.
3. Making a different edit to the same heading line on `main`.
4. Merging `future_header` into `main` and creating a merge conflict.
5. Resolving the conflict and committing the merge.

The final resolved heading is **Future Header**.

To inspect the history, run:

```bash
git log --oneline --graph --all
```
